# AI-Based Student Performance Prediction System

The AI-Based Student Performance Prediction System is a Machine Learning project developed using Python. It predicts students' final academic grades based on their previous grades, study time, number of past failures, and absences.

The project uses the **Linear Regression algorithm** to train a Machine Learning model with the UCI Student Performance dataset. It uses Pandas and NumPy for data processing, Scikit-learn for model training, Joblib for saving the trained model, and Streamlit to create an interactive web application.

Users can enter student details through the web application and receive a predicted final grade along with performance suggestions and a graphical representation of the results.

**Technologies Used:**
- Python
- Machine Learning
- Linear Regression
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Joblib

**Model Evaluation Results:**
- Mean Absolute Error (MAE): 1.34
- R² Score: 0.78

**Main Objective:** To help understand and predict student academic performance using Machine Learning and provide insights that may support better learning outcomes.
